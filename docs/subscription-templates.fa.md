# راهنمای ساختِ قالبِ صفحهٔ اشتراک

> ترجمهٔ فارسیِ `SUBSCRIPTION-TEMPLATES.md`؛ همان متغیّرها و همان قواعد، با
> نمونه‌های آماده. از نسخهٔ `1.0.0-alpha.9.2` در دسترس است.

این راهنما برای کسی است که می‌خواهد صفحه‌ای را که مشترک با باز کردنِ لینکِ اشتراک
در مرورگر می‌بیند، خودش طراحی کند — از صفر تا تست روی سرور.

---

## ۱. این قالب دقیقاً کجا اعمال می‌شود؟

یک کاربر دو نوع درخواست به یک آدرس می‌فرستد و پنل برای هرکدام پاسخِ متفاوتی دارد:

| درخواست‌کننده | چه می‌گیرد | قالبِ شما اعمال می‌شود؟ |
|---|---|---|
| برنامه‌های کلاینت (v2rayNG، Streisand، sing-box، Nekoray…) | فهرستِ لینک‌ها / کانفیگِ clash یا sing-box | خیر |
| مرورگر (Accept دارد `text/html` و User-Agent مرورگری است) | صفحهٔ HTML اشتراک | **بله** |
| مرورگر با `?format=clash` یا `?format=sing-box` | همان خروجیِ کلاینت | خیر |

بنابراین قالبِ شما فقط **ظاهرِ صفحه** را عوض می‌کند؛ پشتِ آن همان لینک‌ها و همان
محدودیت‌هاست. اگر پنل در حالتِ «ورود با برنامه» (`application login`) باشد، اساساً
هیچ مادّهٔ کانفیگی صادر نمی‌شود: `links` خالی است و `apps` (لینک‌های دانلودِ برنامه)
پر است.

## ۲. پنج قدم

1. **قالبِ آغازین را بگیرید.** در پنل: *Subscriptions → subscription page template →
   download starter*. یک فایلِ HTMLِ کامل و کار می‌گیرید که متغیّرها داخلش در
   کامنت توضیح داده شده‌اند.
2. **ویرایشش کنید.** هر ویرایشگری؛ نیازی به ابزارِ خاصی نیست.
3. **آپلود کنید.** همان بخش، دکمهٔ *upload template*. فقط `.html` / `.htm`، حداکثر
   ۲۵۶ کیلوبایت. نامِ فایل پاک‌سازی می‌شود (بدون مسیر؛ هر کاراکترِ عجیب به `-`).
4. **انتخاب کنید.** از فهرستِ همان بخش، فایل را انتخاب و *Save* را بزنید. ذخیره فقط
   «نامِ فایل» را نگه می‌دارد، نه مسیر — برای همین هیچ مقداری نمی‌تواند از پوشهٔ
   قالب‌ها بیرون برود.
5. **تست کنید.** بخشِ ۸ را ببینید.

> **قاعدهٔ طلایی:** اگر قالب پیدا نشود یا هنگامِ اجرا خطا بدهد، پنل به‌جای آن
> صفحهٔ داخلیِ خودش را نشان می‌دهد و علت را در لاگ می‌نویسد. هیچ مشترکی صفحهٔ
> شکسته نمی‌بیند — اشتباهِ شما به پایِ او نوشته نمی‌شود.

## ۳. متغیّرهایی که در اختیار دارید

| متغیّر | نوع | توضیح |
|---|---|---|
| `brand` | رشته | نامِ برند (پیش‌فرض `Zagros`) |
| `app_name` | رشته | نامِ برنامه |
| `support_url` | رشته یا `none` | لینکِ پشتیبانی اگر تنظیم شده باشد |
| `notes` | فهرستِ رشته | یادداشت‌های پنل (مثلاً محدودیتِ یک هسته) |
| `generated_at` | datetime | زمانِ ساختِ صفحه |
| `user` | شیء | مشخّصاتِ کاملِ کاربر (جدولِ پایین) |
| `used_bytes` | عدد | حجمِ مصرف‌شده |
| `data_limit_bytes` | عدد یا `none` | سقفِ حجم (`none` یعنی نامحدود) |
| `remaining_bytes` | عدد یا `none` | باقی‌مانده |
| `expire_at` | datetime یا `none` | زمانِ انقضا |
| `online` | بولین | آیا همین حالا سشن دارد |
| `sections` | فهرست | بخش‌ها بر اساسِ پروتکل (جدولِ پایین) |
| `links` | فهرست | خروجیِ صافِ همهٔ لینک‌ها: `{protocol, title, label, url}` |
| `apps` | فهرست | لینک‌های دانلود: `{platform, name, url, primary}` |
| `page` | شیء | کلِ صفحه (همهٔ فیلدهای بالا به‌علاوهٔ `lang` و `direction`) |

### فیلدهای `user`

`username` · `status` (`active` / `limited` / `expired` / `disabled` / `on_hold`) ·
`online` · `used_bytes` · `data_limit_bytes` · `expire_at` · `remaining_bytes` ·
`user_id` · `client_auth_mode`

### توابعِ کمکی

| تابع | نمونهٔ خروجی |
|---|---|
| `format_bytes(1024)` | `1.00 KB` — برای `none` مقدارِ `∞` |
| `format_date(expire_at)` | `2026/08/30` — برای `none` مقدارِ `—` |

## ۴. ساختارِ بخش‌ها و artifactها

هر بخش یک پروتکل است:

```
sections[] = { protocol, title, engine, note, inbound_tag, artifacts[] }
```

هر `artifact` یکی از چهار نوع است (`kind`):

| `kind` | فیلدهای مهم | یعنی چه |
|---|---|---|
| `link` | `content` (خودِ لینک)، `label` | لینکِ اشتراک؛ برای کپی کردن |
| `file` | `filename`، `content` (متنِ فایل)، `mime` | فایلِ قابلِ دانلود (مثل `.ovpn` یا `.conf`) |
| `fields` | `fields[] = {key, label, value, secret, copyable}` | جدولِ مشخّصات (هاست/پورت/نام‌کاربری…) |
| `note` | `note` | توضیح یا محدودیتی که باید به کاربر گفته شود |

نمونهٔ چرخ‌زدن روی همهٔ بخش‌ها:

```jinja
{% for section in sections %}
  <h2>{{ section.title }} <small>{{ section.protocol }}</small></h2>
  {% if section.note %}<p class="muted">{{ section.note }}</p>{% endif %}

  {% for a in section.artifacts %}
    {% if a.kind == "link" %}
      <a href="{{ a.content }}">{{ a.label }}</a>
    {% elif a.kind == "file" %}
      <a download="{{ a.filename }}"
         href="data:{{ a.mime }};charset=utf-8,{{ a.content | urlencode }}">{{ a.filename }}</a>
    {% elif a.kind == "fields" %}
      <dl>{% for f in a.fields %}
        <dt>{{ f.label }}</dt><dd>{{ f.value }}</dd>
      {% endfor %}</dl>
    {% elif a.kind == "note" %}
      <p>{{ a.note }}</p>
    {% endif %}
  {% endfor %}
{% endfor %}
```

> نکته: مقادیرِ `kind` رشته‌اند (`"link"` نه `link`) چون از enum نصب‌شده روی رشته می‌آیند.

## ۵. قواعدِ مهم

* **قالب Jinja2 است با autoescape روشن.** یعنی `{{ user.username }}` اگر شاملِ
  `<script>` باشد، بی‌خطر چاپ می‌شود. فقط جایی `|safe` بگذارید که خودتان HTML
  نوشته‌اید.
* **عدمِ قطعیت را محترم بشمارید.** `data_limit_bytes` ممکن است `none` باشد و
  `expire_at` هم همین‌طور. قبل از محاسبه چک کنید (`{% if expire_at %}`)، وگرنه
  یا خطا می‌خورید یا عددِ بی‌معنی نشان می‌دهید.
* **داراییِ خارجی ممنوع.** فونت، CSS یا JS از اینترنت نگیرید؛ صفحه برای کاربرانی
  که خودِ پنل را به‌سختی باز می‌کنند باید همان لحظه کامل باشد (صفحهٔ داخلیِ پنل هم
  همین قانون را دارد). هرچه لازم است درونِ فایل باشد.
* **جهت و زبان**: `page.direction` (`rtl`/`ltr`) و `page.lang` در دسترس‌اند؛
  می‌توانید `<html dir="{{ page.direction }}" lang="{{ page.lang }}">` بگذارید.

## ۶. چهار نمونهٔ آماده

### الف) کمینه — فقط نام و لینک‌ها

```jinja
<!doctype html>
<html dir="rtl"><head><meta charset="utf-8"><title>{{ brand }}</title></head>
<body>
  <h1>{{ user.username }}</h1>
  {% for l in links %}<p><a href="{{ l.url }}">{{ l.label }}</a></p>{% endfor %}
</body></html>
```

### ب) نمایشِ حجم با نوارِ پیشرفت

```jinja
{% if data_limit_bytes %}                      {# سقف دارد #}
  {% set pct = (used_bytes / data_limit_bytes * 100) | round(1) %}
  <div class="bar"><span style="width: {{ [pct, 100] | min }}%"></span></div>
  <p>{{ format_bytes(used_bytes) }} از {{ format_bytes(data_limit_bytes) }} ({{ pct }}٪)</p>
{% else %}                                     {# نامحدود: تقسیم بر صفر ممنوع #}
  <p>{{ format_bytes(used_bytes) }} — نامحدود</p>
{% endif %}
<p>باقی‌مانده: {{ format_bytes(remaining_bytes) }} · انقضا: {{ format_date(expire_at) }}</p>
```

> چرا این شرط لازم است: اگر سقف ندارید و مستقیم تقسیم کنید، خروجی «۳٫۰۰ MB از ۰ B
> (۰٪)» می‌شود — هم غلط است و هم کاربر را می‌ترساند.

### ج) جدولِ مشخّصاتِ کامل (همهٔ چهار نوع artifact)

همان قطعهٔ کدِ بخشِ ۴.

### د) رفتارِ درست در حالتِ «ورود با برنامه»

```jinja
{% if apps %}
  <h1>برنامه را نصب کنید</h1>
  {% for a in apps %}
    <a class="store" href="{{ a.url }}">{{ a.name }} <small>{{ a.platform }}</small></a>
  {% endfor %}
{% else %}
  ...حالتِ معمول...
{% endif %}
```

## ۷. اشتباهاتِ رایج

| علامت | علت |
|---|---|
| صفحهٔ پیش‌فرضِ پنل را می‌بینید، نه قالبِ خودتان | یا فایل روی سرور نیست (نام را دوباره آپلود کنید) یا هنگامِ رندر خطا داده — لاگ را ببینید |
| هیچ لینکی چاپ نمی‌شود | یا کاربر لینکی ندارد، یا پنل در حالتِ «ورود با برنامه» است (`links` خالی است، `apps` را چاپ کنید) |
| `0.0٪` یا عددِ عجیب برای درصد | `data_limit_bytes` برابرِ `none` است؛ ابتدا چک کنید |
| کاراکترها به‌هم ریخته | `<meta charset="utf-8">` را فراموش کرده‌اید |
| تغییرات دیده نمی‌شود | مرورگر صفحه را کش کرده؛ با `Ctrl+Shift+R` یا یک تبِ ناشناس امتحان کنید (پاسخ‌ها `no-store` هستند) |

## ۸. تستِ درست (بدون حدس زدن)

```bash
# ۱) لینکِ اشتراکِ کاربر را بگیرید
TOKEN=...   # توکنِ ادمین
curl -s -H "Authorization: Bearer $TOKEN" https://PANEL/api/user/USERNAME \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['subscription_url'])"

# ۲) دقیقاً مثل یک مرورگر درخواست بدهید
curl -s -H "User-Agent: Mozilla/5.0 (X11; Linux x86_64) Chrome/120 Safari/537.36" \
     -H "Accept: text/html,application/xhtml+xml" \
     "https://PANEL/sub/TOKEN"
```

اگر خروجی HTMLِ شما بود، کار تمام است. اگر صفحهٔ داخلیِ پنل آمد، لاگِ کانتینر را
برای علت ببینید:

```bash
docker compose logs zagros | grep -i "subscription template"
```

## ۹. محدودیت‌های فعلی

* **QR در دسترسِ قالب نیست.** صفحهٔ داخلی QR را خودش می‌سازد، اما به قالب فقط
  متنِ لینک داده می‌شود (نیازی به کتابخانهٔ خارجی نیست، چون داراییِ خارجی ممنوع
  است). اگر لازم دارید بگویید تا یک متغیّرِ `qr` اضافه کنم.
* **یک قالب برای همه.** انتخابِ قالب سراسری است، نه به‌ازای هر کاربر؛ اگر تفاوت
  لازم دارید، داخلِ قالب شرط بگذارید (`{% if user.status == 'limited' %}`).
* **بدون دسترسی به شبکه/پرونده.** قالب فقط متغیّرهای بالا را می‌بیند.

# زاگروس (Zagros)

**پلتفرم سازمانی مدیریت VPN چندهسته‌ای** — هسته‌های قابل‌توسعه، سهمیه یکپارچه،
دستگاه‌های یکپارچه و تحویل مهروموم به کلاینت.

در زاگروس هر فناوری VPN یک **پلاگین درجه یک** است؛ Xray هیچ جایگاه ویژه‌ای در
کدبیس ندارد و فقط یکی از Driverهاست.

> **اصالت:** زاگروس بازطراحی عمیق فورک پنل
> [Marzban](https://github.com/Gozargah/Marzban) ‏(AGPL-3.0) به یک پلتفرم
> چندهسته‌ای پلاگین‌محور است. کلیه حق نشر و مجوز AGPL-3.0 نسخه بالادستی
> حفظ شده است (`LICENSE`) و مسیر مهاجرت از Marzban نسخه 0.8.x داخلی و
> تست‌شده است.

## قابلیت‌های کلیدی

* **۸ درایور هسته داخلی** — xray، ‏sing-box، ‏WireGuard، ‏OpenVPN، ‏Hysteria 2،‏
  ‏TUIC v5، ‏SSH، ‏SoftEther — همه پشت یک قرارداد واحد.
* **سهمیه یکپارچه** — یک شمارنده برای هر کاربر روی همه هسته‌ها با baseline
  پایدار (شمارش دقیقاً-یکبار حتی پس از ری‌استارت).
* **مدیریت یکپارچه دستگاه و نشست** — محدودیت دستگاه سراسری و تاریخچه نشست‌ها.
* **موتورهای مرکزی Routing‏ / Outbound ‏/ Policy** با گزارش صادقانه برای هر هسته.
* **زنجیره‌سازی بین هسته‌ها** (Cross-Core Chaining).
* **پرتال اشتراک پویا** — رندر بر اساس آنچه هر Driver اعلام می‌کند؛ دو حالت
  تحویل: لینک اشتراک یا ورود با اپلیکیشن.
* **بک‌اند اپ رسمی** — ورود فقط با نام کاربری/رمز عبور؛ خروج کانفیگ فقط از
  کانال مهروموم (X25519 + HKDF-SHA256 + AES-256-GCM).
* **استودیو کانفیگ** — مدیریت گرافیکی بدون JSON دستی + حالت Advanced با Diff.
* **Persistence مدرن** — SQLAlchemy + Alembic، رمزنگاری Credentialها در حالت
  سکون، مهاجرت ایدمپوتنت با Dry-Run و Rollback.

## توسعه

```bash
pip install -r requirements.txt
python -m pytest tests/
alembic upgrade head
python main.py
```
